`.github/workflows/ci.yml`: one `api` job (checkout@v7, setup-uv@v10 with lockfile cache,

## 06b — Model / cost comparison table

**Alignment with Spec 06 §06b under D29:** no paid run is made, so the deliverable is the tooling
plus its documentation. The table is built from existing run files; token-counting of the prompt
prefix (caching column) needs a provider call and is left out — README says so.

**Files:** `apps/api/src/pitz_pulse/model_compare.py` (CLI), `apps/api/tests/test_model_compare.py`,
`Makefile` (new target `compare-models`), README section.

**Interfaces:**
- `model_compare.Row` (frozen dataclass): `stem, provider, model, temperature (float | None),
  set, scored, field_accuracy: dict[str, tuple[int,int]], exact_match: tuple[int,int],
  mean_input_tokens, mean_output_tokens, cost_per_message_usd, equivalent_cost_per_message_usd,
  attempts_per_message, p50_latency_ms, mock: bool`.
- `build_row(app_root, stem, threshold) -> Row` — reuses `evaluate.load_run` (all integrity
  checks) and `scoring.score` with the set's labels (`labels.LABEL_FILES`); per-message figures
  divide the meta totals (which include retries) by `meta.n`; `cost_per_message_usd` uses
  `total_cost_usd`, the equivalent column uses `total_equivalent_api_cost_usd`.
- `to_markdown(rows) -> str` — header line `# MOCK ROWS PRESENT — NOT MODEL QUALITY` when any row
  is mock; one table per set (case / edge), columns: model · provider · temperature (`—` when
  null) · each scored field accuracy % · exact match · in/out tokens per msg · cost/msg (incl.
  retries) · equivalent API cost/msg · attempts/msg · p50 ms; then a note: "N = <scored> per set;
  differences within the noise floor of two identical runs (make compare) are not meaningful";
  never recommends routing.
- `main(argv=None, env=None) -> int` — `--runs STEM [STEM ...]`; same exit-code contract as
  evaluate (0, or 2 with `error: …`, never a traceback); never builds `LLMSettings`; never writes
  anything (it never touches `/resultados.json`).

**Makefile `compare-models`:** requires `MODELS` (space-separated). For each model:
`$(MAKE) classify SET=case SUFFIX=cmp FORCE=$(FORCE) LLM_MODEL=<model>` and the same for `edge`,
with `LLM_TEMPERATURE=none` when the model is `claude-sonnet-5` (catalog: no temperature); then
runs `model_compare` over the produced stems. Before the loop it prints the models, provider and
`2 × 12+18 messages per model; retries can add calls` and requires `CONFIRM=1` to proceed with a
non-mock provider (prints how to confirm and exits 2 otherwise). Mock needs no confirmation.

**Tests (synthetic runs in a tmp APP_ROOT tree, like `tests/evaluate_support.py`; reuse that
module's builder):** two rows (a mock row and a hand-built `anthropic_api` row with tokens and
cost) → per-message math exact (e.g. 1800 in / 150 out tokens over n → means; cost / n); `—` for
null temperature; MOCK header present only when a mock row exists; separate tables per set;
integrity failure in any run → exit 2 naming the stem; no file is written (compare the tree
before/after). A `make -n compare-models MODELS="a b"` test (skip without `make`) shows two
classify calls per model with `SUFFIX=cmp` and `LLM_TEMPERATURE=none` only for
`claude-sonnet-5`, and that a non-mock provider without `CONFIRM=1` stops.

**Docs:** README §5 gets a "Comparing models" paragraph: the command, that it bills 2 runs per
model, that rows are never promoted, and that routing "simple" cases to a cheaper model is only
proposed after real numbers exceed the noise floor. Spec 06 status line → "06a, 06b implemented".

Global constraints as in previous plans (files < 300 lines, ruff, no new deps, no real calls,
conventional commits with body + trailer).
