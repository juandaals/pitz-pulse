## Medium (applied)

- Real Agent SDK raises `ResultError` after yielding the error result → mapping rewritten against real-shaped stubs; bare `Exception` from `query` wrapped.
- Mutation-surviving tests: meta-first order (spy on `os.replace`), exact meta key set, `input_sha256`, cancellation.
- Real Ctrl-C blocked until in-flight calls finished → abandon in-flight (`shutdown(wait=False, cancel_futures=True)`), report the count; tested by interrupting the main thread.
- Unexpected exception lost earlier billed attempts → attempts collected in a per-call sink; `ClassificationCrash` carries them.
- Unknown `LLMError.kind` produced no log line → logged as `error`, then `RuntimeError`.
- Exit codes: config/prompt/JSON errors → exit 2 with message; writability checked before spending; `--help` exits 0.
- All-rejected run wrote `[]` and blocked the retry → nothing written.
- `ruff check` failed on the plan's own code (29 errors) → imports fixed, `ruff format` + `ruff check --fix` step in every task.
- Whitespace bypassed the 4000-char limit → raw length ≤ 8000 also enforced.
- `LLMSettings` repr printed credentials → `repr=False`.
- `LOG_LEVEL` unvalidated; `LLM_TEMPERATURE=""` fatal in mock → validated / ignored in mock.
- Over-masking: RFC ate `del 230415 com`; year lists/year-months masked → uppercase-only separated RFC, guards for year lists and year-months.
- Model mismatch warned on every call (snapshot ids) → prefix match; `actual_model` recorded.
- Template placeholders and duplicate sections validated at load; tool name not hard-coded.
- v1 boundary rules were written with the case labels in view → disclosed in `prompts/CHANGELOG.md`.
- Agent SDK like-for-like: `thinking` disabled; single version check at startup; process-wide semaphore; cache tokens in equivalent cost.
