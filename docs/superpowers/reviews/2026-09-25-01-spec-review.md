## Review summary

The classification flow itself is sound (the graph terminates, masking order has no collisions,
the Anthropic API path works as designed). The risk concentrates on the edges: configuration
semantics that make two documented provider paths impossible under compose (temperature),
run-file naming that lets the wrong run become the deliverable, and an Agent SDK adapter whose
only fallback cannot work. Privacy is mostly covered for the message, but `source_area`, tracing,
CLI transcripts and several real-world PII formats slip through.

Highest-severity: **HB** (temperature "empty" semantics), **HD + HG** (run naming + promote checks),
**HR** (Agent SDK adapter design), **HT** (evaluator silently gets mock).

### Medium / Low themes (from slices, not individually verified)

- **Limits:** `INVALID_OUTPUT_RETRIES` 0–3 and `LLM_MAX_RETRIES` 0–5 validated; explicit LangGraph `recursion_limit`; attempt counting 1-based, tested N=0 → 1 call, N=1 → 2 calls.
- **Prompt:** field descriptions state 20 words / Spanish / nullability; feedback template lives in the versioned prompt; data-not-instructions sentence required and tested; delimiter neutralization after NFKC incl. opening-tag spoofs; D14 overlap check in Spec 01 `test_prompts.py`; `refusal` stop reason counts as invalid output.
- **Batch:** failures listed in meta (run still written, exit 1, promote refuses); Ctrl-C cancels queued futures; first `llm_rejected` aborts the batch; concurrency test asserts peak == min(concurrency, n); suffix validated `^[a-z0-9-]{1,20}$`; model id sanitized in stem; repo-relative `input_file`; run JSON shape fixed (list of 10-key objects, `null` kept).
- **Providers:** Anthropic mapping by status (`APIConnectionError`, 408/409/429/≥500 → unavailable; other 4xx → rejected); Agent SDK error mapping table (`ResultMessage.is_error`, `AssistantMessage.error`, `CLINotFoundError`, …); explicit `env` for the CLI subprocess blanking non-selected credentials and our secrets; `ANTHROPIC_BASE_URL` / `ANTHROPIC_AUTH_TOKEN` / `CLAUDE_CODE_USE_*` validated; process-wide semaphore in the Agent SDK adapter; startup readiness (CLI path, writable `HOME`); temperature value finite in [0,1]; `.env` values stripped, quotes rejected.
- **Logging:** third-party loggers (`anthropic`, `httpx`, `httpcore`, `langchain*`, `langgraph`) pinned to WARNING; 500 `detail` constant; `equivalent_api_cost_usd` in `LLMCall`, log and meta.
- **Config sources:** one source for the active `PROMPT_VERSION` (code default = compose default = `.env.example`, tested); `api.py` exposes a factory (`uvicorn --factory`), no module-level app.
- **Fixtures:** synthetic PII uses invalid check digits, `example.com` domains, repeated-digit phones.
- **Spec hygiene:** header coverage (R1.9 belongs to 03), decisions list, G-ids in §10, MASTER §6 test names, env inventory rows (`APP_ROOT`, `SLACK_CHANNEL_AREAS`, tracing vars).

## Proposed MASTER.md updates (for candidate approval)

- **D23** Official `resultados.json` comes from `anthropic_api` at temperature 0; promote enforces
  provider, temperature, set, ids and full contract. Agent SDK = development provider. *(candidate
  decided 2026-09-25)*
- **D24** Agent SDK adapter: `claude-agent-sdk` used directly (no LangChain wrapper), plain JSON
  reply + graph validation/retry, full isolation option set, explicit subprocess env, hard deadline.
- **D25** Provider selection: provider unset + exactly one credential → that provider; mock
  responses carry `X-Pitz-Provider: mock`.
- **D26** Run stems include the golden set; runs are never overwritten without `--force`;
  `eval/runs/` is committed after every real run.
- **G30** temperature three-state semantics · **G31** tracing egress · **G32** Agent SDK transcripts
  and env inheritance · **G33** no hard per-invoke deadline · **G34** masking format coverage.
